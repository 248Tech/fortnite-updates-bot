Fortnite news, delivered to your Discord.

A small, modular Discord bot that fetches Fortnite news from FortniteAPI.io and posts it as tidy embeds. Slash commands and legacy prefix commands for Battle Royale, Save the World and Creative.

▶ Try it in a simulated channel★ View on GitHub

No Discord login needed — the demo runs the bot’s command logic in your browser with fictional sample news.

What it does

Focused on doing one job well, with the plumbing a real bot needs.

📰

Clean news embeds

Numbered fields, category tags and a hero image, trimmed to stay inside Discord’s 25-field and 6000-character limits.

⌨️

Slash & prefix commands

/fortnite_updates with a type picker, plus legacy !fortnite_updates [br|stw|cre] — with an editable prefix.

⚙️

Runtime configuration

Admins change language, default mode, prefix and ephemeral replies from Discord. Settings persist to bot_config.json.

🛡️

Resilient networking

Async aiohttp with a 10 s timeout and friendly error embeds for HTTP, timeout and parse failures.

🌍

Language aware

Set a default language in .env or per server with /config set_language.

🧩

Modular code

API client, embed builder, config store and command handlers live in separate small files that are easy to extend.

Commands

Everything below works in the demo, including the permission checks.

CommandWhoWhat it does
/fortnite_updates [type]
!fortnite_updates [br|stw|cre]		EveryonePost the latest news for Battle Royale, Save the World or Creative.
/config showManage ServerShow prefix, language, default mode and ephemeral setting.
/config set_language · !setlangManage ServerSet the news language (empty = .env default).
/config set_default_mode · !setmodeManage ServerStore the preferred news mode.
/config set_ephemeral · !setephemeralManage ServerMake slash replies visible only to the caller.
/config set_prefix · !setprefixManage ServerChange the legacy command prefix.

Architecture

Four small modules, one responsibility each.

bot.py

discord.py command tree and prefix commands; shared handler for both command styles.

fortnite_api.py

Async FortniteAPI.io client that normalizes several response shapes into one news item type.

embeds.py

Builds the embed with safe truncation and Discord limit handling.

config_manager.py

Persistent, non-secret settings in JSON; secrets stay in .env.

Run your own

You need Python 3.10+, a Discord bot token and a FortniteAPI.io key.

  1. Clone and set up
    git clone https://github.com/248Tech/fortnite-updates-bot.git
cd fortnite-updates-bot
./setup.sh --run        # Windows: .\setup.ps1 -Run
  2. Add your secrets to .env:
    DISCORD_TOKEN=your_discord_bot_token
FORTNITE_API_KEY=your_fortniteapi_io_key
NEWS_LANGUAGE=en
  3. Invite the bot to your server and run /fortnite_updates.
